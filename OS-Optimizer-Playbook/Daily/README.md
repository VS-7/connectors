# Layer 2 — Daily Logs & Scratchpads

**Purpose:** Notas diárias, anotações rápidas e registros de trabalho do dia.

## Padrão

- Notas desta pasta são efêmeras e servem para capturar ideias brutas. Periodicamente, insights duráveis são promovidos para `Context/` ou `Projects/` pelo processo de **Reflection (F8)** do Optimizer.
