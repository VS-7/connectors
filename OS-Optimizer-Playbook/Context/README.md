# Layer 1 — Context & Canonical Knowledge

**Purpose:** Canonical, durable facts about the operator, business, customers, team, and technology. This layer changes slowly and represents foundational truth.

## Children

- [[identity]] — Operator background, tone of voice, core principles, personal operating style.
- [[company]] — Business model, core offer, value proposition, pricing structure, strategic focus.
- [[icp]] — Ideal Customer Profile, acute pain points, key objections, decision triggers.
- [[team]] — Key team members, external contractors, decision-making authorities, communication channels.
- [[tech-stack]] — Active software tools, APIs, automation workflows (n8n, Make, scripts), platforms.

## Rules for Layer 1
- **High Signal:** Avoid rambling notes. State facts clearly in bullet points or tables.
- **Reference from Layer 2:** Active projects in `Projects/` should link back to items here via `[[company]]`, `[[icp]]`, etc.
