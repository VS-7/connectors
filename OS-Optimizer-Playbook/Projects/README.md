# Layer 2 — Projects (Active Work Units)

**Purpose:** Repositório central de iniciativas ativas, entregáveis em andamento e marcos prioritários do negócio.

## Children
- [[active-projects]] — Visão consolidada de todas as iniciativas em andamento com status, prazos e donos.

## Padrão de Projeto
Cada projeto complexo pode ter seu próprio arquivo dedicado nesta pasta: `Projects/{slug-projeto}.md`.
Todo projeto ativo deve conter:
1. Objetivo claro (Definition of Done)
2. Responsável e Stakeholder
3. Tarefas pendentes com checkbox (`- [ ]`)
4. Links para decisões tomadas em `[[Decisions/]]`
